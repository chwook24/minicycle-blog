How to add the MiniCycle widget to your iPhone home screen

Published June 15, 2026·by Chanwook Kim, MiniCycle developer·Updated September 2, 2026·3 min read

At a glance

The MiniCycle widget is a small square on your home screen that answers one question before you open anything: where am I in my cycle right now. Putting it there takes about five taps. The only real friction is finding the right screen the first time, so here is the whole path, plus what the widget can and can't do once it is sitting there.

Add the small widget

Touch and hold an empty part of the home screen until the icons jiggle. Tap Edit, choose Add Widget, and search for MiniCycle. Select MiniCycle and tap Add Widget, then place it where you want and tap Done.

MiniCycle currently supports only the small square family, so there is no medium or large size to choose. The exact button labels can vary slightly by iOS version; Apple's current widget guide is linked below.

What the widget shows

The widget shows four weeks of dates with today included. It uses the app's saved period records and prediction settings to mark period, estimated fertile-window, and estimated ovulation dates. It does not display a date selected inside the app.

The week-start and language settings are shared with the app. The widget uses the same prediction code, but iOS can keep an older timeline cached for a while, so the two screens are not guaranteed to update at the same instant.

If the widget looks empty or out of date

Until you log at least one period start, the widget intentionally shows a start-tracking state. Add or correct the record inside MiniCycle, then return to the home screen.

Opening MiniCycle writes the latest shared data and requests a widget reload, but iOS decides when to redraw it. Allow a little time. If it remains stale, remove the widget and add it again. The widget has no separate week-start setting; it reads the setting saved by the app.

For a step-by-step refresh check, see Why the MiniCycle widget isn't updating, and how it refreshes.

What the widget leaves off on purpose

The widget is built for reading, not recording. It does not show your daily notes or your private activity marks, and it has no buttons to edit a date. Those live inside the app, where there is room for them and where the Face ID hide option can protect the more sensitive parts.

This matters most on a shared or glanced-at phone. A home screen is visible to anyone who picks up the device, so the widget keeps to cycle predictions and leaves notes and activity logging behind the app. Open the app when you need to add a period, fix an end date, or write a note. The widget is there for the quick look.
