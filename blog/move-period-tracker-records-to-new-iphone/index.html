How to keep your period tracker records when moving to a new iPhone

Published May 23, 2026·by Chanwook Kim, MiniCycle developer·Updated September 2, 2026·3 min read

At a glance

MiniCycle records are stored on the iPhone by default. Before changing phones, choose either MiniCycle's optional iCloud Sync or an Apple device-transfer or backup method. If you use MiniCycle iCloud Sync, sign in with the same Apple ID on the new iPhone, open MiniCycle Settings, enable iCloud Sync there, and wait for synchronization before checking the calendar.

Start with the right expectation

MiniCycle does not automatically fetch a CloudKit copy merely because the new iPhone uses the same Apple ID. On the new phone, enable iCloud Sync in MiniCycle Settings to start the fetch-and-restore path, then check the status message for completion or an error.

If you leave MiniCycle iCloud Sync off, use Apple's device migration or backup restoration so the app's local data can move with the rest of the phone.

Use Apple's transfer or backup flow

Apple's main migration options include Quick Start direct transfer and restoring from an iCloud or computer backup. Follow one of Apple's current procedures before treating the new iPhone as your only copy.

If you use a computer backup, review Apple's encrypted-backup guidance when you want to protect personal data in that backup. Apple's support pages are the source of truth for current screens and requirements.

Check MiniCycle before erasing the old iPhone

After the new iPhone is set up, open MiniCycle and review the calendar before wiping the previous device. Check that recent period starts, end dates, notes, statistics, and widget state look reasonable. This is faster than trying to reconstruct dates later from memory.

Before using the reset control, read How to reset MiniCycle and erase all your period records.

If you are switching from another period app

MiniCycle does not currently import records automatically from other period-tracking apps. If the previous app offers an export, keep that file for your own records and manually enter the period starts you trust most.

A practical migration checklist

Keep the old iPhone until the new one is verified. On the new phone, open MiniCycle and check recent starts, end dates, notes, and statistics. If using MiniCycle iCloud Sync, enable it on the new phone and confirm synchronization. Erase or trade in the old device only after the records are present.
