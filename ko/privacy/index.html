MiniCycle

개인정보 처리방침

MiniCycle은 간단한 생리 캘린더에 필요한 것만 최소한으로 다루도록 설계했습니다.

앱 기록

생리 날짜, 메모, 성생활 표시, 주기 설정은 기본적으로 사용자의 기기 안에 저장됩니다. MiniCycle 앱 사용에는 MiniCycle 계정이 필요하지 않습니다.

선택적 iCloud 저장

앱 설정에서 iCloud 저장을 켜면 MiniCycle은 Apple CloudKit을 사용해 앱 기록과 설정의 사본을 사용자의 비공개 iCloud 계정에 저장합니다. 같은 Apple ID로 로그인한 새 iPhone에서 기록을 복원하기 위한 기능이며, MiniCycle은 별도의 자체 동기화 서버를 운영하지 않습니다.

앱 분석

MiniCycle은 앱 열기, 화면과 탭 이동, 달력 조작, 일반화된 핵심 동작 완료, 위젯 설치 상태와 탭 유입, 일반 설정 변경, 알림 권한 결과, 온보딩 진행, 선택적 iCloud 동기화 상태 같은 사용 흐름을 이해하기 위해 Firebase Analytics를 포함합니다. MiniCycle 사용자 정의 이벤트에는 생리 날짜, 메모 내용, 성생활 표시, 기록 유형, 기록 입력 위치, 정확한 주기 설정값, 정확한 알림 시간, 주기 기록을 넣지 않도록 설계했습니다.

Firebase Analytics는 Google 문서에 따라 자동 수집 이벤트, 앱 인스턴스 식별자, 마스킹된 IP 주소에서 추정한 대략적인 위치, 앱과 기기의 기술 정보도 처리합니다. MiniCycle은 Analytics 사용자 ID를 설정하지 않고, Analytics용 Apple IDFV를 수집하거나 광고 개인화 및 앱 간 추적에 Analytics 데이터를 사용하지 않습니다.

선택적 앱 내 피드백 (2026년 10월 10일 갱신)

사용자가 앱에서 피드백 보내기를 선택하면 분류, 메시지, 무작위 제출 식별자, 앱 버전, 빌드 번호, iOS 버전이 서울 리전의 Firebase 및 Google Cloud 피드백 서비스로 전송됩니다. 개발자는 문의 대응, 오류 조사, 앱 개선을 위해 메시지를 읽을 수 있습니다. 생리 기록, 저장된 메모, 성생활 기록, Analytics 식별자는 자동으로 첨부되지 않습니다. 이름, 연락처, 민감한 건강 정보는 메시지에 넣지 말아 주세요.

Firebase 익명 인증은 별도의 가입 화면 없이 인증과 남용 방지에 사용할 익명 계정 식별자를 생성하고, App Check와 App Attest는 요청을 검증합니다. 피드백 문서에는 인증 식별자 원문이나 IP 주소를 저장하지 않습니다. Google 서비스는 인증·앱 검증 정보와 서버 접속 기록의 IP 주소 등 요청 정보를 별도로 처리합니다.

피드백은 90일 후, 전송 횟수 제한 기록은 2일 후 자동 삭제되도록 설정되며 실제 삭제는 비동기로 처리됩니다. 인증 계정, 서버 로그, Telegram 알림 정보에는 별도의 서비스 보관 정책이 적용됩니다. 개발자의 비공개 Telegram 알림에는 분류, 앱 버전, 접수 식별자, Firebase 콘솔 링크만 포함되고 메시지 본문, 인증 식별자, 주기 기록은 전달되지 않습니다. 피드백은 광고나 앱 간 추적에 사용하지 않습니다. 삭제 문의는 가능한 경우 대략적인 전송 시각과 분류를 적어 chwookqwe@gmail.com으로 보내주세요.

웹사이트 분석

MiniCycle 웹사이트는 페이지 조회, 유입 경로, 블로그 사용 흐름을 파악하기 위해 Google Analytics를 사용합니다. 웹사이트 분석은 MiniCycle 앱 기록과 별개이며, 앱 안의 생리 날짜, 메모, 주기 기록을 포함하지 않습니다.
