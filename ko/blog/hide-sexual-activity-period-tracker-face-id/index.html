MiniCycle 성생활 기록 숨기기와 Face ID 해제 방법

게시 2026년 6월 11일·작성 김찬욱, MiniCycle 개발자·업데이트 2026년 9월 2일·약 3분 읽기

핵심 답변

MiniCycle에서는 성생활 기록을 삭제하지 않고 달력 화면에서 숨길 수 있습니다. 숨기기는 즉시 적용되며, 다시 표시하려면 Face ID 인증이 필요합니다. 이 기능이 가리는 화면과 가리지 않는 설정, Face ID를 사용할 수 없는 기기에서의 제한을 설명합니다.

성생활 기록을 남기는 방법

달력에서 날짜를 선택한 뒤 하트 모양 버튼을 누르면 해당 날짜 아래에 작은 보라색 점이 나타납니다. 다시 누르면 기록이 삭제됩니다.

보라색 점은 생리 기록과 추정 가임기 옆에 표시되지만, 이를 피임이나 임신 가능성 판단에 사용해서는 안 됩니다.

숨기기 설정이 바꾸는 것

설정에서 성생활 숨기기를 켜면 달력의 보라색 점, 범례의 성생활 항목, 선택한 날짜 패널의 하트 버튼이 보이지 않게 됩니다. 다만 설정 화면의 숨기기 스위치는 그대로 남습니다. 성생활 기록 기능의 존재까지 감추는 기능이 아니라, 달력 화면에서 기록을 가리는 기능입니다.

기록을 숨길 때는 별도의 인증을 요구하지 않습니다. 스위치를 켜는 즉시 달력에서 표시가 사라집니다.

다시 표시할 때 Face ID가 필요한 이유

숨긴 기록을 다시 표시하려면 MiniCycle이 iOS의 LocalAuthentication을 통해 Face ID 인증을 요청합니다. 인증에 실패하거나 취소하면 기록은 계속 숨겨진 상태로 남습니다.

MiniCycle이 얼굴 정보 자체를 받는 것은 아닙니다. 앱에는 iOS가 돌려주는 인증 성공 여부만 전달됩니다. 이 기능은 앱 안의 표시 설정을 보호할 뿐이며, iPhone 잠금 비밀번호 같은 기기 보안을 대신하지는 않습니다.

숨기기는 삭제가 아닙니다

걱정부터 풀고 가겠습니다. 이 스위치는 아무것도 지우지 않습니다. 기록은 기기 안에 그대로 있고, Face ID를 통과하면 모든 점이 원래 날짜로 돌아옵니다. 한 달을 숨겨 두었다 풀어도 빠지는 건 없습니다.

반대도 사실입니다. 숨겨 둔 동안에는 기록 버튼도 함께 사라지므로 새로 남기거나 지울 수 없습니다. 기록을 정말 없애고 싶다면 그건 다른 동작입니다. 날짜를 누르고 하트 버튼을 꺼서 하루씩 지우거나, 설정의 데이터 초기화로 앱의 모든 기록을 한꺼번에 지울 수 있습니다. 초기화는 되돌릴 수 없습니다.

앱의 전체 기록을 삭제하는 별도 작업은 「MiniCycle 기록 초기화: 무엇이 지워지고 무엇이 남나요」 글에서 설명합니다.

미리 알아 둘 한계

해제에는 Face ID만 받습니다. Touch ID도, 잠금 비밀번호도 대신할 수 없습니다. 그래서 홈 버튼이 있는 SE 계열처럼 Face ID가 없는 기기에서는 해제할 수 없다는 안내만 나옵니다. Face ID를 설정해 두지 않은 경우도 마찬가지입니다. 내 기기에서 Face ID가 안 된다면, 되돌릴 생각으로 숨기기를 켜지 않는 편이 안전합니다.

이 기능이 막아 주는 범위도 분명히 해 두겠습니다. 열려 있는 달력을 향한 시선, 그러니까 빌려준 휴대폰이나 책상 위 화면 같은 노출을 막는 장치입니다. 기기 자체의 보안은 잠금 비밀번호의 몫입니다. 하나 더하자면, 홈 화면 위젯에는 성생활 기록이 애초에 표시되지 않습니다. 숨기기 설정과 무관하게, 가장 공개적인 화면은 처음부터 비워 두었습니다.

기록은 어디에 저장되나요

성생활 기록은 다른 MiniCycle 기록과 함께 기본적으로 기기에 저장됩니다. iCloud 동기화를 켜면 같은 Apple 계정의 다른 iPhone과 동기화할 수 있도록 Apple CloudKit에도 사본이 저장됩니다. 자세한 내용은 개인정보 처리방침에서 확인할 수 있습니다.

숨기기 스위치는 MiniCycle 화면에 표시할지 여부만 바꿉니다. 기록을 암호화하거나 삭제하거나 다른 저장소로 옮기지는 않습니다. 옆에 표시되는 가임기와 배란일도 추정값이며 의료 조언, 피임 수단, 임신 확인 수단이 아닙니다.
