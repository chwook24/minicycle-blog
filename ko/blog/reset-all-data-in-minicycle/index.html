MiniCycle 기록 초기화: 무엇이 지워지고 무엇이 남나요

게시 2026년 6월 14일·작성 김찬욱, MiniCycle 개발자·업데이트 2026년 9월 2일·약 3분 읽기

핵심 답변

기록 초기화는 MiniCycle 설정 맨 아래에 있는 되돌릴 수 없는 작업입니다. 확인 창에서 초기화를 누르면 저장된 모든 생리 구간과 날짜별 기록이 삭제됩니다. iCloud 저장이 켜져 있으면 비워진 상태도 업로드하려고 하므로, iCloud 저장을 초기화 전 상태로 되돌리는 별도 보관용 백업으로 생각해서는 안 됩니다.

지워지는 기록과 남는 설정

초기화하면 모든 생리 시작일과 종료일, 날짜별 메모, 성생활 표시가 삭제됩니다. 선택한 달만 지우는 기능이 아닙니다. 앱은 홈 화면 위젯 새로 고침도 요청하지만 실제 반영 시점은 iOS가 결정합니다.

화면 모드, 언어, 주기 길이, 생리 기간, 주 시작 요일, 알림 설정은 앱에 남습니다. 기록 초기화는 앱 재설치나 iPhone 전체 초기화와 다릅니다.

초기화 방법

MiniCycle 설정에서 맨 아래의 빨간 ‘기록 초기화’를 누릅니다. 이어지는 확인 창에서 취소를 고르면 아무 기록도 바뀌지 않습니다. 빨간 초기화 버튼을 누르면 기록이 즉시 삭제되며 앱 안에서 되돌릴 수 없습니다.

날짜 하나만 잘못 기록했다면 해당 생리 기록을 수정하거나 삭제하세요. 전체 초기화는 한 기록을 고치는 방법이 아닙니다.

iCloud 저장은 초기화 백업이 아닙니다

iCloud 저장이 켜져 있으면 기기 기록을 지운 뒤 비워진 상태를 CloudKit에 업로드하려고 합니다. 업로드에 성공하면 동기화된 상태도 비워집니다. 네트워크나 iCloud 계정 문제로 동기화가 실패할 수 있으므로, 모든 사본이 즉시 바뀌었다고 가정하지 말고 동기화 상태를 확인하세요.

초기화 직전에 iCloud 저장을 켠다고 초기화 전 상태가 독립적으로 보관되지는 않습니다. MiniCycle 밖에 반드시 남겨야 할 정보가 있다면 초기화를 누르기 전에 별도로 옮겨 두세요.

기기를 바꾸거나 이전 기록을 지우기 전에는 「새 아이폰으로 옮길 때 MiniCycle 생리 기록을 지키는 방법」 글도 확인하세요.

초기화한 뒤

생리 시작일이 하나도 없으면 다음 예정일을 계산할 기준점도 없습니다. 새 시작일을 기록한 뒤에도 자료가 부족하면 자동 설정에서 주기 29일과 생리 기간 5일을 사용합니다.

기록 초기화만으로 다른 사람에게 넘길 iPhone의 준비가 끝나는 것은 아닙니다. 기기를 양도할 때는 Apple의 계정 로그아웃과 전체 기기 지우기 안내를 따르세요.
